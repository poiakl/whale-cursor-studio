# AI 直接使用工坊 · MCP

MCP 直接连接正在运行的工坊，读取当前界面并调用软件功能。修改立即出现在当前方案中，支持工坊的撤销。软件未打开时，组件会尝试打开同目录的工坊。

## 接入

1. 完整解压便携版，保留同目录的 `WhaleCursorStudio.exe` 和 `WhaleCursorMCP.exe`。
2. “设置 → AI 连接 · MCP → 复制连接配置”，添加到支持本地 stdio MCP 的 AI 客户端，再重新连接。
3. 在工坊“AI 生图”页勾选需要的动画，配置参考图、角色要求、各级提示词、帧数和尺寸。
4. 告诉 AI：“读取工坊的生图任务，用你的生图能力生成这些动画，再直接放回对应动画。”

生图使用调用方 AI 自己的能力；AI 客户端须具备可调用的生图功能。MCP 会提供真实参考图片与完整任务文本，工坊无需配置生图 API 密钥。工坊 AI 页原有的手动 API 发送仍可单独使用。

3.4 起取消列文件、新建文件方案、通用导入导出等 MCP 工具，也无需再创建工作目录或提交方案副本。旧连接参数可启动新版组件，但建议重新复制配置并刷新客户端工具列表。

## 软件专有工具

| 工具 | 功能 |
| --- | --- |
| get_generation_request | 取得 AI 页当前勾选任务的完整提示词、帧数、尺寸、排版、热点及真实参考图片；可按目标 id 分批读取 |
| apply_generated_image | 把 AI 已生成的本地图片或 base64 直接回填对应动画；按请求自动切帧、应用热点和时长，可传返回的热点 JSON |
| get_interaction_settings | 读取当前点击素材、动画参数、音效，以及关键帧语法和示例 |
| set_click_effect | 编写并直接应用点击关键帧和效果参数 |
| preview_click_effect | 返回工坊真实渲染的效果图和各进度姿态，供 AI 检查动作 |
| configure_interaction_audio | 配置触发音频、随机／顺序、播完再播、触发间隔和音量 |

例子：

- “读取当前勾选的点击装饰任务，按参考图生成，然后放回 effects.click。”
- “让当前点击素材向右弹跳三次，最后淡出；写入关键帧，预览检查。”
- “将这两个 WAV 用作左键点击音效，按顺序播放，播完再播，触发间隔 500 毫秒。”

生成请求返回 `request_id`。回填时提供该 id 与目标 id，图片选择 `image_path` 或 `image_base64`。生成期间若用户切换方案或修改了该动画，工坊会拒绝覆盖，需要重新读取任务。修改可以撤销，MCP 不自动安装系统指针。

## 点击关键帧

`keyframes` 是 2～64 个 JSON 对象；t 从 0 到 1 且不能重复。支持 x、y、scale、rotation、opacity。x/y 是相对点击位置的像素偏移，右／下为正。中间自动插值；持续时间单独设置。该格式是动作数据，不执行任意程序。

## 音效规则

- 随机／顺序决定下一次选哪段音频。
- **播完再播**：等待当前音频结束，新触发只保留最新一次待播，避免快速点击积压；关闭后允许重叠。
- **触发间隔**：同一触发两次开始播放的最短间隔，单位毫秒，0 不限制。未到间隔的触发被忽略，不推进顺序位置。
- 移动、闲置、长按等连续触发设置非零间隔后，可在条件持续时重复播放；条件结束会取消该连续触发的待播。
- 音频为未压缩 PCM WAV；音效及参数随完整方案和相应单动画包保存。

## 源码启动

安装 requirements.txt 后，由客户端运行 `python mcp_entry.py --editor <main.py绝对路径>`。组件通过当前用户的本地管道连接工坊，通信不开放网络端口。Windows 便携版无需 Python。更新后请退出旧版工坊，再重新连接。
